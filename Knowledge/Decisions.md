# Decisions

Format per entry: `ADR-###` · title · date · status · context · decision · consequences.
Statuses: `accepted` · `superseded by ADR-###` · `reversed`.

Never edit a past decision's text to change its meaning — supersede it with a new ADR and update the
old one's status line only.

```
## ADR-### — <title>
**YYYY-MM-DD · accepted**

**Context.** <the forces at play; what made a decision necessary>

**Decision.** <what was chosen, and the main alternative rejected>

**Consequences.** <what this costs, what it makes easier, what it rules out>
```
