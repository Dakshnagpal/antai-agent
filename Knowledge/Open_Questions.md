# Open Questions

**This file is the only home for open questions.**

Format: `OQ-###` · the question · what it gates · status (`open` / `answered` / `dropped`).

An open question **never halts work.** Proceed under a stated assumption, log it as an `Inferred` ledger
entry, and flag it. When answered, record the decision as an ADR in [Decisions.md](Decisions.md) and set
the status here to `answered` with a link.

```
**OQ-### — <the question?>**
Status: open. Gates <what cannot be settled until this is answered>. Assumption in use: <...> (#ledger).
```
